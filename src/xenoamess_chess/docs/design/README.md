# xenoamess_chess 设计草案 v0.1

这是一款以棋盘、形状组合和单位解体为核心的双人回合制电子游戏。玩家使用共同的基础单位表，通过生产基础组件、按形状组合单位和选择指挥官，发展不同的战术。

本文档整理自[最初讨论](discuss/1.md)及后续对话。原始讨论保留，当前规则以本目录的整理稿为准。当前是用于首轮对局的设计提案，还没有实现对应玩法。

## 阅读顺序

- [核心规则](rules.md)：行动力、回合、组合、耐久、解体、多棋盘及试玩开局。
- [基础阵营的 10 种单位](units.md)：形状、配方、费用、耐久、伤害与单位职责。

## 已确认的设计方向

| 事项 | 当前约定 |
| --- | --- |
| 游戏形式 | 双人轮流行动的电子游戏 |
| 棋盘 | 从 16 × 16 起步，可以付费增加棋盘，规则上不设棋盘数量上限 |
| 行动力 | 棋手初始每回合获得 1 点，用于部署等棋手操作 |
| 部署范围 | 可以在任意已开放棋盘上的合法位置部署，没有己方部署区限制 |
| 单位费用 | 不同单位消耗不同的行动力，并可能要求不同形状的祭品 |
| 入场等待 | 手动部署、工厂生产的单位在入场当回合不能行动，特殊技能可以例外 |
| 解体归属 | 解体后的组件留在棋盘上，继续归原玩家所有；嵌套组合递归拆到基础组件 |
| 基础组件 | 无法继续拆分的组件被消灭时，直接从棋盘移除 |
| 耐久 | 接受可累计的简化耐久；单位耐久耗尽前保持全部功能，耗尽后才解体或移除 |
| 阵营 | 双方共享基础单位表，通过不同指挥官产生差异 |

耐久是本轮讨论最终采用的方向，替代原始草稿的默认“一次命中立即解体”。受伤不会自动降低生产量、移动距离、射程或伤害。

## 本次补充的试玩提案

以下是为了让草案可以进行首轮对局而补充的规则，还需要测试和继续讨论：

- 单位行动与棋手行动力分开；各单位每个己方回合行动一次。
- 未花完的行动力跨回合保留，使每回合收入为 1 时也能支付高费用单位。
- 使用伤害和当前／最大耐久两组小整数，不增加防御力、伤害类型或受击次数盾。
- 攻击命中自动结算，没有命中率与随机暴击，也没有自动反击。
- 原型中的所有基础组件均为 minion；其他九种单位通过配方组合而来。
- 引入可连接的棋盘区块、固定的首轮扩张价格和一个用于验证战斗的胜负目标。
- 基础阵营扩充为 10 种单位，另提供 3 个可选指挥官草案。

## 设计重点

1. 让耐久只承担“能承受多少攻击”的职责，数值集中在 1～5，状态直接显示在棋盘上。
2. 让形状决定组合条件、占地、通过空间和攻击接触面。
3. 让组件保留产生二次争夺：打散一个工厂可以中断生产，但清掉它留下的材料还需要继续投入行动。
4. 用单体伤害、范围攻击、生产、维修和运输区分单位，不要求十种单位各自建立一套独立子系统。

## 当前边界

首轮试玩使用公开棋盘和公开单位配方，不加入战争迷雾、随机抽牌或隐藏单位。“卡表”在这一版中指可选择的单位集合；牌库构筑和抽牌是否加入，留待后续决定。

单位的费用、耐久、伤害、射程、扩张价格和胜利目标都是起始测试值。首先验证“复合单位能否正常发挥功能”和“解体后的组件争夺是否有趣”，再调整具体数值。
